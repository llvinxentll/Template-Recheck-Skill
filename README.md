# TULIBS Thesis DOCX Checker

สกิลตรวจไฟล์ Word (.docx) วิทยานิพนธ์ / สารนิพนธ์ / การค้นคว้าอิสระ ของมหาวิทยาลัยธรรมศาสตร์
เทียบกับเทมเพลตของหอสมุด (TULIBS ไทย/อังกฤษ rev.2024 และ English Times rev.2023)
พร้อมตรวจการอ้างอิง APA 7 แยกตามภาษาของแต่ละรายการ แล้วออกรายงาน `.docx` ไฟล์เดียว

## ผลลัพธ์

รายงาน `<ชื่อไฟล์>_report.docx` แยก 3 ตาราง:

| ตาราง | ตรวจอะไร |
|---|---|
| 1. รูปแบบเทมเพลต | หน้ากระดาษ · ระยะขอบ · ฟอนต์/ขนาด · สไตล์ TU_* · เลขหน้า · โครงสร้างเล่ม · สารบัญ · การเยื้องหัวข้อ · ตารางส่วนนำ |
| 2. คำผิด | คำสะกดผิด · อักขระผิดรูป/แปลกปลอม · เว้นวรรคซ้อน · คำซ้ำ |
| 3. การอ้างอิง APA 7 | รูปแบบรายการอ้างอิงและการอ้างอิงในเนื้อหา แยกกฎไทย/อังกฤษต่อรายการ |

**ทุกแถวระบุจุดด้วย "ข้อความจริงในเล่ม" ไม่ใช่เลขหน้า** — ผู้อ่านก๊อปข้อความไปวางใน Ctrl+F
แล้วกระโดดถึงจุดนั้นได้ทันที เพราะเลขหน้าเลื่อนทุกครั้งที่แก้ไฟล์

## วิธีใช้

```bash
# 1) ตรวจ (โหลด DOCX ครั้งเดียว รันตัวตรวจสองชุด)
python3 scripts/check_all.py "thesis.docx" --auto-json auto.json --deep-json deep.json

# 2) ออกรายงาน (ต้องส่ง --docx ไฟล์ต้นฉบับไปด้วยเสมอ)
python3 scripts/make_report.py auto.json deep.json --docx "thesis.docx" \
    -o "thesis_report.docx" --title "<ชื่อวิทยานิพนธ์>"
```

ต้องมี `python-docx` (`pip install python-docx`) ไม่ต้องติดตั้ง LibreOffice หรือโปรแกรมอื่น
— ทุกอย่างอ่านจาก OOXML ในไฟล์โดยตรง

## โครงสร้าง

```

scripts/
  check_all.py               ทางหลัก — เรียกตัวตรวจทั้งสองชุด
  check_docx.py              ค่าตั้งค่า: หน้ากระดาษ ระยะขอบ ฟอนต์ สไตล์ สี คำผิด
  check_deep.py              โครงสร้างเล่ม + APA 7 เชิงกลไก
  make_report.py             สร้างรายงาน 3 ตาราง
  verify_report.py           ตรวจโครงสร้างรายงานโดยไม่ต้องสร้างใหม่
  split_docx.py              แบ่งงานสำหรับโหมดขนาน (เล่มหนา)
  test_false_positives.py    ชุดทดสอบกันกฎฟ้องสิ่งที่ถูกอยู่แล้ว
references/
  docx-spec.md               เกณฑ์รูปแบบ 3 โปรไฟล์ (ค่าจริงจากเทมเพลต)
  style-catalog.md           ค่าสไตล์ TU_*
  inspection-checklist.md    รายการที่ต้องตรวจด้วยตา
  apa7-tha-parts/            คู่มือ APA 7 หอสมุด มธ. (ไทย) ซอยตามประเภทแหล่ง
  apa7-eng/                  ตัวอย่าง APA Style (อังกฤษ) แยกไฟล์ตามประเภทแหล่ง
  agent-contracts.md         สัญญาผลลัพธ์สำหรับโหมดขนาน
```

## กฎที่ยึดตลอด

1. **false positive แพงกว่าการตรวจไม่เจอ** — นักศึกษาเสียเวลาแก้สิ่งที่ถูกอยู่แล้ว
   แล้วเลิกเชื่อรายงานทั้งฉบับ ทำให้ finding ที่ถูกต้องพลอยถูกมองข้าม
   ไม่แน่ใจระหว่าง "ผิด" กับ "ตรวจไม่ได้" → เลือก "ตรวจไม่ได้" เสมอ
2. **ทุกแถวต้องตอบได้ว่า "ตรงไหนในเล่มของฉัน"** — แถวที่ชี้จุดไม่ได้คือแถวที่แก้ไม่ได้
   ต่อให้เนื้อหาถูกต้อง
3. **ไฟล์ตัวอย่างของหอสมุดคือเกณฑ์** — กฎใดที่ฟ้องไฟล์ตัวอย่าง แปลว่ากฎนั้นผิด
   `scripts/test_false_positives.py` บังคับเงื่อนไขนี้อยู่ ให้รันทุกครั้งหลังแก้กฎ

## ข้อมูลที่ไม่อยู่ในรีโพนี้

ไฟล์วิทยานิพนธ์จริงที่ใช้ทดสอบและรายงานผลตรวจ **ไม่ถูก commit** (ดู `.gitignore`)
เพราะมีชื่อ-นามสกุล รหัสนักศึกษา และเนื้อหางานที่ยังไม่เผยแพร่
