# กรณีพิเศษของเล่มวิทยานิพนธ์ (เปิดเมื่อเจอสถานการณ์ตรงกับหัวข้อ)

แยกจาก SKILL.md เพราะแต่ละข้อใช้เฉพาะบางเล่ม การแบกไว้ใน SKILL.md ทำให้ทุกงานต้องจ่ายค่าโหลดโดยไม่ได้ใช้

- **.doc เก่า / Google Docs export**: แปลงก่อน (`libreoffice --headless --convert-to docx`)
- **ไม่ได้ใช้เทมเพลต**: สคริปต์รายงานว่าสไตล์ TU_* หาย → แนะนำก๊อปเนื้อหาลงเทมเพลตต้นฉบับ
- **หน้า landscape**: ระยะขอบสลับ (L1.0 R1.5) ถูกต้อง สคริปต์จัดการแล้ว
- **เล่มไทยมีปกอังกฤษแทรก / บทคัดย่อสองภาษา**: ถูกตามเทมเพลต ไม่ใช่ error
- **ฟอนต์สมการ (Cambria Math/MT Extra)**: ยกเว้นเฉพาะ run ภายใน Office Math; ถ้าใช้กับร้อยแก้วถือว่าผิด
- **english-times (rev.2023)**: อังกฤษ Times 12pt + ไทย TH Sarabun 16pt + บรรทัด 1.5 — อย่าเอาเกณฑ์ 2024 ไปตรวจไฟล์ 2023
- **รายการอ้างอิงผสมภาษา**: ตรวจแต่ละรายการตามภาษาของรายการนั้น
- **แหล่งอ้างอิงไม่มีในรายการประเภท**: เปิดไฟล์ประเภทใกล้เคียงที่สุดแล้วปรับใช้
- **ไฟล์ PDF**: สกิลนี้ตรวจ .docx — ขอไฟล์ Word จะตรงกว่ามาก. ถ้ามีผล PDF เป็น JSON อยู่แล้ว ป้อนเข้า `make_report.py` แทน `auto.json` ได้
