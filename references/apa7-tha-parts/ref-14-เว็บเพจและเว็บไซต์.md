### (14) เว็บเพจและเว็บไซต์ (Webpages, Websites)

*(หน้า 56)*

**รูปแบบ**

```
ผู้แต่ง.\(วัน เดือน ปีที่เผยแพร่).\ชื่อเรื่อง.\ชื่อเว็บไซต์.\URL
```

กรณีที่ไม่ปรากฏปีที่เผยแพร่ ให้ลงวันที่ค้นข้อมูลแทน

```
ผู้แต่ง.\(ม.ป.ป.).\ชื่อเรื่อง.\ชื่อเว็บไซต์.\สืบค้นเมื่อวันที่,\จาก\URL
```

สำหรับภาษาต่างประเทศ

```
–
```
*(ต้นฉบับคู่มือเว้นว่างไว้)*

**เครื่องหมาย \ หมายถึง เว้นวรรค 1 ระยะ**

- กรณีที่ปรากฏเฉพาะปี ค.ศ. หรือ พ.ศ. ให้ใส่แค่ปีเท่านั้น
- กรณีชื่อผู้แต่งและชื่อเว็บไซต์เป็นชื่อเดียวกัน <u>ให้ตัดชื่อเว็บไซต์ออก</u>
- ไม่ต้องใส่เครื่องหมายมหัพภาค (.) หลัง URL หรือเว็บไซต์
- ไม่ต้องขีดเส้นใต้ URL หรือเว็บไซต์
- กรณี URL ยาวมาก ให้พิมพ์ต่อบรรทัดใหม่ ทั้งนี้ควรเป็นข้อความ
- ที่อยู่หลังเครื่องหมายทับ (/) หรือก่อนเครื่องหมายมหัพภาค (.)
