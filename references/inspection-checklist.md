# Checklist อ่านยืนยัน (.docx) — ใช้ประกอบขั้นที่ 3–5

บันทึกผลทุกข้อ: ✅ ผ่าน / ❌ ไม่ผ่าน (ระบุตำแหน่ง+ค่าที่พบ) / ⚠️ ตรวจไม่ได้

**กฎ:** อ่านค่ารูปแบบผ่าน python-docx/XML เท่านั้น; PDF ที่ layout engine สร้างใช้เฉพาะระบุ **แผ่นงานทางกายภาพ**. ทุกข้อ ❌ ต้องระบุ `แผ่นที่ N` (นับปกเป็น 1) + section/สไตล์/ย่อหน้า/ข้อความขึ้นต้น + ค่าที่พบจริง + ค่าเกณฑ์ + วิธีแก้.

## หมวด A — สคริปต์ตรวจให้แล้ว (ทวนผลจาก auto/deep JSON)
- [ ] A1 หน้ากระดาษ A4 ทุก section
- [ ] A2 ระยะขอบ portrait 1.5/1.0/1.5/1.0, landscape สลับ
- [ ] A3 ฟอนต์ถูก profile (ไม่มี Angsana/Cordia/Calibri/TNR ผิดที่)
- [ ] A4 ขนาดและค่า drift ของ named styles (body/heading); ขนาดชื่อปก 20pt อ่านยืนยันใน B1
- [ ] A5 ระยะห่างบรรทัดตรง profile (2024 เดี่ยว / 2023 Times 1.5)
- [ ] A6 สไตล์ TU_* ครบ ค่าไม่เพี้ยน
- [ ] A7 สีดำล้วน
- [ ] A8 ลำดับ heading บทถูกต้อง

## หมวด B — ต้องเปิดอ่านเองหรือยืนยันเมื่อสคริปต์ครอบคลุมไม่ครบ

> 🅿️ = เกณฑ์ที่ขึ้นกับการจัดหน้าจริง ตรวจได้ต่อเมื่อ `scripts/page_truth.py` คืน `page_claims_allowed: true` มิฉะนั้นให้ลงว่า "ตรวจไม่ได้จากไฟล์ ต้องเปิดดูใน Word" (กฎความแม่นยำข้อ 3)

### B1 หน้าปกใน / ปกภาษาที่สอง
- [ ] องค์ประกอบครบ 8 บรรทัด เรียงถูก กึ่งกลาง หนา
- [ ] 🅿️ องค์ประกอบทั้งหมดอยู่ในแผ่นเดียวกัน — **ต้องมี `pagemap.json`** ไม่มีให้ข้าม
- [ ] ชื่อเรื่อง 20pt
- [ ] ปีการศึกษา: ปกไทยใช้ **พ.ศ.**, ปกอังกฤษใช้ **ค.ศ. (ACADEMIC YEAR 20XX)**
- [ ] ชื่อผู้เขียนไม่มีคำนำหน้า (นาย/นาง/นางสาว) — ตามข้อบังคับ (ฉบับที่ 3) พ.ศ.2565
- [ ] เล่มไทย rev.2024 = ตัดหน้าปกในไทยออก (ขึ้นด้วยชื่อเรื่อง แล้วมีปกอังกฤษ) — ถูกต้อง

### B2 หน้าอนุมัติ
- [ ] เลือกแบบเดียว (แบบ 1 ที่ปรึกษาเดี่ยว / แบบ 2 มีที่ปรึกษาร่วม) ไม่ผสม
- [ ] กรรมการครบตามแบบ + เส้นเซ็นชื่อ + วงเล็บ (ตำแหน่งวิชาการ ชื่อ สกุล)
- [ ] วันที่อนุมัติ + คณบดี

### B3 บทคัดย่อ (ทั้งสองภาษา)
- [ ] ตารางข้อมูลครบ 6 รายการ (หัวข้อ/ผู้เขียน/ปริญญา/สาขา-คณะ-มหาวิทยาลัย/อาจารย์ที่ปรึกษา/ปีการศึกษา)
- [ ] หัวข้อ "บทคัดย่อ"/"ABSTRACT" กึ่งกลาง 18pt
- [ ] 🅿️ เนื้อหา ≤ 1 หน้า — **ต้องมี `pagemap.json`** ไม่มีให้ข้าม (ห้ามเดาจากเลขแผ่นของ marker)
- [ ] ทวน finding อัตโนมัติของ **คำสำคัญ:/Keywords:**; อ่านเองเมื่อข้อความถูกแบ่งเป็นโครงสร้างผิดปกติ
- [ ] เลขหน้าเริ่ม (1) ที่หน้านี้

### B4 กิตติกรรมประกาศ / สารบัญ
- [ ] 🅿️ กิตติกรรมประกาศ ≤ 1 หน้า — **ต้องมี `pagemap.json`**; ชื่อผู้เขียนชิดขวาท้ายหน้า (ไม่มีคำนำหน้า) ตรวจได้ปกติ
- [ ] สารบัญ: มีครบทุกส่วนที่มีจริง, คำว่า "หน้า"/"Page" ชิดขวา
- [ ] เลขหน้าในสารบัญที่ deep check จับคู่ไม่ได้/ไม่มี Word markers; มิฉะนั้นสุ่มยืนยันรายการสำคัญ
- [ ] ส่วนนำใช้ (1)(2), เนื้อหาใช้ 1 2 3
- [ ] สารบัญตาราง/ภาพ ตรงกับของจริง (สุ่ม 3 รายการ)

### B5 เนื้อหา
- [ ] "บทที่ X"/"CHAPTER X" กึ่งกลาง 18pt + ชื่อบทบรรทัดถัดไป
- [ ] ชื่อบทอังกฤษ = ตัวพิมพ์ใหญ่ทั้งหมด, ใช้ "CHAPTER 1" ไม่ใช่ "Chapter 1"
- [ ] ทวน finding เลขบทต่อเนื่อง/หน้าเริ่มบทจาก deep check
- [ ] ไม่มีหัวข้อลอยท้ายหน้า (heading orphan)

### B6 ตาราง / ภาพ
- [ ] caption ตาราง/ภาพ — **สคริปต์ไม่ตรวจแล้ว** (แยก caption จากประโยคเนื้อหาที่ขึ้นต้นเหมือนกันไม่ได้) ถ้าจะตรวจต้องอ่านเอง
- [ ] เลข = บท.ลำดับ, เรียงตามที่ปรากฏ
- [ ] ตารางตกหน้า: ทวนหัวตาราง + (ต่อ)/(Continued)

### B7 รายการอ้างอิง / ภาคผนวก / ประวัติ
- [ ] ทวน hanging indent/ฟอนต์/ขนาดจากสคริปต์; ตรวจ Thai collation และความสม่ำเสมอที่เหลือด้วยการอ่าน
- [ ] หน้าคั่นภาคผนวก: คำเดียว 20pt กึ่งกลางหน้า; ภาคผนวก ก/ข/ค หรือ A/B/C
- [ ] ประวัติผู้เขียน (ถ้ามี) = หน้าสุดท้าย; ถ้าตัดออกต้องไม่อยู่ในสารบัญ; ยกเลิกวันเดือนปีเกิด (rev.2024)

## เกณฑ์สรุปผลรวม
- **ยังไม่พบปัญหา:** ไม่มี finding แต่ต้องยืนยันหมวด B ก่อนส่ง
- **พบเฉพาะจุดเล็กน้อย:** มี minor เท่านั้น
- **ควรแก้จุดสำคัญ:** มี major แต่ไม่มี critical
- **ต้องแก้ก่อนส่ง:** มี critical หรือผิดเชิงระบบ (ฟอนต์/ระยะขอบ/สไตล์/โครงสร้าง)

ไม่สร้างเปอร์เซ็นต์จากจำนวน finding เพราะไม่มีตัวหารจำนวนข้อที่ตรวจได้จริง.
