# เทมเพลตทางการ TULIBS — เนื้อหาที่สกัดจากไฟล์ .docx ต้นฉบับ

ไฟล์ในโฟลเดอร์นี้คือ **แหล่งความจริงของเกณฑ์รูปแบบทั้งหมด** สกัดจากเทมเพลตต้นฉบับ
โดยตรง (styles.xml · sectPr · เนื้อหาทุกย่อหน้าพร้อมชื่อสไตล์และค่าฟอนต์)

| ไฟล์ | โปรไฟล์ในสกิล |
|---|---|
| `TULIBS-Thesis-Template-Thai-rev2024.md` | `thai` |
| `TULIBS-Thesis-Template-English-rev2024.md` | `english` |
| `TULIBS-Thesis-Template-English-TimesNewRoman-rev2023.md` | `english-times` |

## เปิดเมื่อไร

ไฟล์ละ ~2,300 บรรทัด **อย่าเปิดทั้งไฟล์เพื่อตรวจเล่มปกติ** — ค่าที่ใช้บ่อยถูกย่อไว้ใน
`references/docx-spec.md` แล้ว. เปิดไฟล์นี้เฉพาะตอน:

- สงสัยว่ากฎในสคริปต์ถูกหรือไม่ (เช่น "หน้าปกต้องมีบรรทัดลิขสิทธิ์ไหม" → ค้นคำนั้นในไฟล์)
- ต้องรู้ค่าของสไตล์ที่ `docx-spec.md` ไม่ได้ย่อไว้
- จะเพิ่มกฎใหม่ — ต้องยืนยันจากไฟล์นี้ก่อนเสมอ ไม่ใช่จากความจำหรือจากเอกสารตัวอย่าง

## วิธีค้นเร็ว

```bash
# ค่าของสไตล์หนึ่ง ๆ ในทั้งสามโปรไฟล์
grep -A3 '^### สไตล์: `TU_Sub-heading 1`' references/templates/*.md

# หัวข้อในเนื้อหาใช้สไตล์อะไร
grep -n '^\*\*\[TU_' references/templates/TULIBS-Thesis-Template-Thai-rev2024.md
```

## ข้อควรระวังที่เคยพลาดมาแล้ว

- **หน้าปกไม่มีบรรทัด "ลิขสิทธิ์ของมหาวิทยาลัยธรรมศาสตร์" / "COPYRIGHT OF THAMMASAT
  UNIVERSITY"** ทั้งสามเทมเพลต — บรรทัดนี้อยู่ในเอกสารตัวอย่างรุ่นเก่าเท่านั้น
- **โปรไฟล์ Times rev.2023 ใช้ขนาดสองชุด** — สไตล์หัวข้อยังเป็น TH Sarabun CS 16pt
  แต่สไตล์ย่อหน้าเนื้อความเป็น Times 12pt ทั้ง ascii และ CS
- **`TU_Main Heading_Chapter6/7/8` ตั้งค่าไม่เหมือน Chapter1–5** ในเทมเพลตอังกฤษ
  ทั้งสองรุ่น จึงไม่ถูกนำมาเทียบเกณฑ์
